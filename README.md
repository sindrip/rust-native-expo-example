# rust-native-expo-example

## Prerequisites

- [rustup](https://rustup.rs)
- [mise](https://mise.jdx.dev/getting-started.html)
- [Xcode](https://developer.apple.com/xcode/) (for iOS builds)
- Android NDK (for Android builds): `brew install --cask android-ndk`

## Getting started

Install tools:

```sh
mise install
just setup
```
